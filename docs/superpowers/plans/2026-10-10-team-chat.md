# Team Chat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A chat box for the Team Lobby and the game: filtered, rate-limited free text and quick replies, `/commands` (info, `/ping`, your-view `/weather` and `/light`), mute, and ping markers on the map and mini-map.

**Architecture:**
- **Pure rules** (`src/chat/`): text cleaning and masking, display names, ping places, and `runCommand`. Nothing here imports React.
- **Connection** (`src/game/team.ts`, `src/net/`, `src/hooks/useTeamSession.ts`): `chat` and `ping` are new `TeamMessage` types on the existing connection. The session checks the sender against the roster and rate-limits what it receives.
- **Feed** (`src/hooks/useChat.ts`): one hook holds the last 50 lines, the draft, the mute list and the send rates. `App` holds the team feed (so the conversation carries from the lobby into the game); each solo game has its own.
- **Screens:** one `ChatPanel` (lobby and game), LOG | CHAT tabs on `EventLog`, mute buttons in the lobby, ping markers, and a weather/light override in the scene.

**Tech Stack:** React 19, TypeScript strict (`tsc -b` also type-checks tests), Vite 8, Tailwind 4, Vitest 5 + jsdom 29 + Testing Library / user-event, Playwright from `/opt/node22/lib/node_modules/playwright` (browser check, scratchpad only).

**Spec:** `docs/superpowers/specs/2026-10-10-team-chat-design.md`. The spec is the authority for every word of copy, every rate and every rule; this plan points at the spec section instead of repeating it. Read both.

## Global Constraints

- **No new dependencies.**
- **Copy is verbatim from the spec**, including quotes, `…`, `—` and the `>` glyph. Where this plan says "spec §X", copy from that section exactly.
- **Limits:** 120 characters (`CHAT_MAX`); 480 UTF-16 units raw on receipt (`RAW_CHAT_MAX`); you send one message a second and one ping every 5 s; on receipt a chat token bucket of 3 refilling 1 per second per roster sender, and a ping less than 4 s after the same sender's last accepted ping is dropped; the feed keeps 50 lines.
- **All chat rates use wall time, `Date.now()`**, never the session's join-order `now` or `teamClock`. Tests drive them with `vi.useFakeTimers()`.
- **Teammate text is plain text**: no links, no HTML, in its own `<bdi>`.
- **Quick replies:** game `On my way`, `Need help`, `Meet at the gate`, `Found it!`, `Wait for me`, `Good job!`; lobby `Ready!`, `Wait for me`, `Hi!`; hidden in solo.
- **Placeholders:** `Chat, or /help` (team) and `Command, or /help` (solo). The input is `type="text"`, `maxLength` 120, `enterKeyHint="send"`, `autoComplete="off"`, 16 px on coarse pointers (`pointer-coarse:text-base`).
- **44 px:** on coarse pointers the tabs, quick replies, `[ Quick replies ]`, the input, `[ SEND ]` and the lobby mute buttons use `pointer-coarse:min-h-11`.
- **Notes** start with a `>` glyph (`aria-hidden`); a refusal note identical to the newest line replaces it.
- **Team compatibility:** older clients ignore the new message types (`parseMessage` returns `null`); a mixed room still plays.
- **Commands:** `npm test`, `npx tsc -b`, `npm run build`; single files with `npx vitest run <path>`.

## Review Focus

1. **A burst after a network stall** (three chats arriving within 50 ms, then a fourth). Expected: the first three show, the fourth is dropped, and a sustained 2 a second is held to about 1 a second. Pinned in Task 4.
2. **A muted classmate who reloads** (new id, same nickname). Expected: still muted, and their ping rings still draw while their ping lines never appear. Pinned in Tasks 6 and 13.
3. **The lobby → game switch.** Expected: the lobby lines, the half-typed draft and every mute carry over, and the CHAT unread count starts at 0, not at the whole lobby history. Pinned in Task 13.
4. **Enter or an arrow key while a control has focus.** Expected: Enter on a focused map button still opens that place and never switches tabs; ArrowRight on the focused LOG tab selects CHAT and the explorer doesn't move. Pinned in Task 9.
5. **A rude word split by a zero-width character, and a filler-only message.** Expected: `fu<ZWSP>ck` is masked, a message of only invisible characters sends nothing. Pinned in Tasks 1 and 6.

### Task 6: The feed — `useChat`

**Files:**
- Create: `src/hooks/useChat.ts`, `src/hooks/useChat.test.tsx`

**Interfaces:**
- Consumes: Tasks 1, 2, 4, 5.
- Produces:
  ```ts
  export type ChatLine = { seq: number; kind: "mine" | "teammate" | "ping" | "note"; senderId: string | null; key: string | null; name: string; color: string; text: string };
  export type PostResult = { status: "sent" | "refused" | "command"; effect: CommandEffect | null };
  export type ChatFeed = {
    lines: ChatLine[];                       // muted players' messages and ping lines filtered out
    draft: string; setDraft(draft: string): void;
    muted: readonly string[];                // nickname keys
    mute(name: string): void; unmute(name: string): void;
    post(text: string, context: CommandContext): PostResult;
  };
  export function useChat(session: TeamSession | null): ChatFeed;
  export const lastSeq: (lines: readonly ChatLine[]) => number;                       // 0 when empty
  export const countUnread: (lines: readonly ChatLine[], seenSeq: number) => number;  // teammate and ping lines above seenSeq
  ```
  **Behaviour (spec §"The chat feed", §"Safety rules")**
  - `post`: clean the text; blank → `refused`, no note; starts with `/` → `runCommand`, add its notes, `command`; other text in `solo` → the note `Solo game: start a command with /, for example /help.`, `command`; otherwise a message: mask, `clampChat`, refuse with `Slow down: one message a second.` if under 1 s since your last sent message (`Date.now()`), `sendChat`; `"offline"` → note `Not sent: reconnecting.`, `refused`; else add a `mine` line and `sent`. Commands never count toward the message limit.
  - A `ping` effect: refuse under 5 s since your last sent ping (`Wait a moment before pinging again.`), `"offline"` → `Not sent: reconnecting.` (the refusal replaces the command's own notes, the effect is dropped, the status stays `command` so the input clears); otherwise `sendPing` and the command's notes. `mute`/`unmute` effects update the feed's own list. The effect is returned for the caller (the game draws your own ring).
  - Subscribes to `session.onChat`/`onPing`: a muted sender's chat is not added; a muted sender's ping adds **no** line; display names come from `displayNames(session.players)` (latest, via a ref); a line keeps its arrival colour; ping lines use `pingLine`.
  - Cap 50 lines; `seq` increases; an identical refusal note replaces the newest line.
  - Team feed (`session` given) starts empty and adds the note `Chat with your team here. Type /help for commands.` when `phase` first becomes `lobby` or `playing`; it clears (lines, draft, mutes, rates) when `phase` becomes `idle` or `error`, never when the expedition starts. Solo feed (`null`) starts with `Type /help for commands.`
